# 📊 AnaliseDeBigData_SenacNI2026
Repositório para registro de materiais e atividades feitos em Análise de Big Data Senac Nova Iguaçu (2026). 
Criado para documentar minha evolução no processamento, análise e visualização de dados, dividindo os aprendizados de acordo com as Unidades Curriculares (UCs) do curso.

---

## 📚 Estrutura do Curso e Habilidades Desenvolvidas

### [📁 UC1 - Fundamentos e Processamento de Dados](./UC1)
Nesta primeira etapa, o foco foi estruturar o raciocínio analítico e aprender a manipular bases de dados brutas para extrair os primeiros insights.
*   **Lógica de Programação:** Domínio de estruturas de controle e repetição em Python.
*   **ETL (Extração, Transformação e Carga):** Limpeza, tratamento e estruturação de dados utilizando **Polars** e Pandas.
*   **Estatística Descritiva:** Aplicação de conceitos de amostragem e métricas estatísticas para compreender o comportamento dos dados.
*   **Análise Exploratória:** Criação das primeiras visualizações e cruzamento de informações.

### [📁 UC2 - Análise Avançada e Visualização de Dados](./UC2)
Na segunda etapa, o foco avançou para a construção de soluções de dados mais completas, conectando scripts de processamento com ferramentas de Business Intelligence (BI).
*   **Scripts de Análise Avançada:** Automação de processamento de dados complexos (ex: análise de variáveis de tempo vs. profundidade).
*   **Modelagem para BI:** Estruturação de bases de dados formatadas especificamente para consumo em dashboards.
*   **Visualização de Dados:** Construção de painéis interativos e relatórios dinâmicos no **Power BI**.
*   **Storytelling com Dados:** Apresentação de resultados e insights de forma clara e voltada para a tomada de decisão (integração com apresentações executivas).

## 🛠️ Tecnologias e Ferramentas
Ao longo dos projetos destas duas UCs, as principais tecnologias utilizadas foram:

*   **Linguagens:** Python
*   **Bibliotecas de Dados:** Polars, Pandas
*   **Bibliotecas de Visualização:** Matplotlib, Seaborn
*   **Ferramentas de BI:** Power BI
*   **Ambiente de Desenvolvimento:** VS Code, Jupyter Notebook
